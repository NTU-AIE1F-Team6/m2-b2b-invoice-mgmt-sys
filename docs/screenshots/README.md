## Capture procedure

1. Use the deployed Vercel revision intended for submission.
2. Use only synthetic demo records; do not expose `.env.local`, browser storage, API URLs, or real
   personal/company data.
3. Use a consistent desktop viewport (recommended 1440 x 900) and optionally one mobile viewport.
4. Capture complete UI states without browser password managers, notifications, or unrelated tabs.
5. Optimise PNG files for repository size while keeping text readable.
6. Add descriptive alt text where each image is embedded in README/slides.
7. Record the deployed revision/date below.
